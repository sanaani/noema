# Adversarial diagnosis of the saturated Horn task

This is a disclosed diagnostic on the already examined canonical-v3 population,
not a new confirmatory result and not Phase 5 pair mining. Preserve previous
measurements; revise their interpretation if evidence supports a task failure.

Use all 12 fixed evaluation theorems and the exact archived cross-prover split.
Before new interventions, fix these tests:

1. Exhaustively evaluate every initial context on all 256 truth assignments.
   Construct and Lean-verify a witness that each context is equivalent to the
   conjunction of all eight atoms. Test the common conclusion separately.
2. Check whether every retained state preserves its initial premise context.
   Count distinct formal goals; measure between-theorem versus within-theorem
   centroid dispersion using the original cached state vectors.
3. Replace every cloud by its context-only embedding or by the same context
   paired with one common goal, p0. These controls contain no proof variation.
4. Rotate gallery contexts by one theorem, preserving each gallery's actual
   goal samples. Score the original theorem alignment and the context-donor
   alignment. A result following donor identity implicates context carriage.
5. Replace all contexts by the first theorem's context, retaining original
   goals; also report the existing goal-only comparison. These are encoding
   counterfactuals, not newly accepted Lean proof states.

Run all interventions for syntax, exact truth tables and the already pinned
MiniLM. Use no new significance claims; publish all distance matrices and
intervention outcomes. Equivalent truth-table contexts cannot explain distinct
text centroids through denotation alone. Separate this representational fact
from proof-goal frequency differences and the statement self-match ceiling.

The next study must use a relationship label independently checked by a
symbolic/Lean oracle, a nongeometric crossed surface/structure design, a cheap
baseline/centroid headroom gate and a genuinely Lean-trained encoder arm.
Do not reuse the old population for intersection discoveries or interpret its
ceiling as a universal falsification of the theorem-cloud hypothesis.
